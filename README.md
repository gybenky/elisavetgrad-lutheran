# Єлисаветград, лютеранська парафія Св. Марії (ф. 834 ДАКО)

Презентаційний сайт для МАН: родини, статистика, родинні гнізда, скани метричних записів.

Сайт статичний: `index.html` + файли `*.json` + папка `scans/`. Єдина зовнішня залежність — Chart.js 4.4.1 з cdnjs (потрібен інтернет).

## Публікація на GitHub Pages
1. Створіть репозиторій на github.com і завантажте в його корінь **вміст** цієї папки (index.html, *.json, scans/, .nojekyll).
2. Settings → Pages → Source: «Deploy from a branch», гілка `main`, папка `/ (root)` → Save.
3. Через 1–2 хвилини сайт відкриється за адресою `https://<ім'я>.github.io/<репозиторій>/`.

Локальний перегляд: `python3 -m http.server` у цій папці, далі http://localhost:8000.
Увага: репозиторій має бути публічним, інакше Pages на безкоштовному тарифі не працюватиме. Скани архівних документів публікуйте лише за умов доступу, дозволених архівом.
